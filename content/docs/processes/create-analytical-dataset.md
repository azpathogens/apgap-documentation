# Create an Analytical Dataset

An Analytical Dataset is a named, curated collection of sequence files that you want to analyze together. You can request files owned by your lab and others. The way to request both types of files is to create a dataset containing the desired files.

> [!WARNING]
**The permissions required for this operation are Lab Director or Bioinformatics User**

1. **To create an Analytical Dataset**
   1. Click Data Catalog on the left sidebar
   1. Search for and select files in the Data Catalog
   1. Once all files are selected, click on the "Create Analytical Dataset From Selected" button at the top 
   1. Enter a title and description for the dataset 
   1. Choose the lab and project it will be associated with 
   1. Then click the "Submit for Approval" button at the bottom right

If any files you selected belong to labs you aren't a member of, the dataset status will show **PENDING** until the Lab Directors of the other labs have approved your access requests. You'll be notified as each decision is made.
Files from labs you already have access to are added immediately.
