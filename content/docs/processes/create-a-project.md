# Create a project
Projects live inside labs and provide an isolated workspace for a specific analysis effort. Each project has its own Bioinformatics Users, Seqera workspace, and Vertex Notebook workspace.

> [!WARNING]
> **The permissions required for this operation are Lab Director**

1. Click **Projects** tab
1. Click **Add** **Project**
1. Fill in the **Project** **Title** — note that project titles cannot contain spaces
1. Add a project description
1. Check **Deploy Seqera workspace**
1. Click **Create** **Project**  
  **Note**: Creating a project triggers provisioning of a Seqera workspace in the background. This takes a few minutes. The Seqera workspace will be available once provisioning is complete.
